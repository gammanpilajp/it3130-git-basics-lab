# IT3130 Git Basics Lab
## Purpose
This repository demonstrates a basic Git workflow for IT3130.
## Files
- HelloWorld.html - a small web page used to practise version control
- README.md - project documentation
## Commands practised
git init, git status, git add, git diff, git commit, git log, git remote, git push

## What I learned section
The staging area acts as a preparation zone where you can selectively gather modified files before permanently recording them. Once staged, creating a commit captures a permanent snapshot of those specific changes to build your local repository's history. Finally, remotes are hosted versions of your repository (like on GitHub) where you can push your local commits to securely back up your work and collaborate with others.
